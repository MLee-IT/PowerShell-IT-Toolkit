# Network Information

## Purpose

Displays basic network information from the Windows computer.

## Usage

Run the script:

```powershell
.\scripts\network-info.ps1
```

## Information Displayed

- Network adapter information
- IP addess information
- Default gateway
- DNS server information
- Network connectivity details

## Troubleshooting Use

This tool can help gather basic network information when investigating connectivity, configuration, or communication problems.

## Output

The script displays network information in the terminal.
