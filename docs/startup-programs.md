# Startup Programs

## Purpose

Displays programs configured to start automatically with Windows.

## Usage

Run the script:

```powershell
.\scripts\startup-programs.ps1
```

## Information Displayed

- Program name
- Startup command
- Startup location
- Associated user

## Troubleshooting Use

This tool can help identify programs that automatically start with Windows. Reviewing startup programs can help when investigating slow startup timees or unexpected applications launching when a user signs in.

## Output

The script displays startup programs in a table for easier review.
