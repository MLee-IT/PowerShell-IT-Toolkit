# Service Check

## Purpose

Checks Windows services and displays their current status.

## Usage

Run the script:

```powershell
.\scripts\service-check.ps1
```

## Information Displayed

- Windows service name
- Display name
- Current status

## Troubleshooting Use

This tool can help identify Windows services that may be stopped or unavailable when troubleshooting system features or applications.

## Output

The script displays Windows service information in the terminal.
