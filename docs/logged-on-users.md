# Logged-on Users

## Purpose

Displays users currently logged onto the Windows computer.

## Usage

Run the script:

```powershell
.\scripts\logged-on-users.ps1
```

## Information Displayed

- Logged-on user information
- Associated Windows session information

## Troubleshooting Use

This tool can help identify active user sessions when troubleshooting account, session, or access-related issues.

## Output

The script displays currently logged-on user information in the terminal.
