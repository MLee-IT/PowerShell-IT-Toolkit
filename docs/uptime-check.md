# Sysytem Uptime Check

## Purpose

Displays how long the Windowa computer has been running since its last boot.

## Usage

Run the script:

```powershell
.\scripts\uptime-check.ps1
```

## Information Displayed

- Last boot time
- Number of days the system has been running
- Number of hours the system has been running
- Number iof minutes the system has been running

## Troubleshooting Use

The script displays the last boot time and the current system uptime.
