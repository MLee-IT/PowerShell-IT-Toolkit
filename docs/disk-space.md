# Disk Space

## Purpose

Checks available storage space on the computer's disk drives.

## Usage

Run the script:

```powershell
.\scripts\disk-space.ps1
```

## Information Displayed

- Drive name
- Total disk space
- Used disk space
- Available disk space
- Free space percentage

## Troubleshooting Use

This tool can help identify low disk space when investigating slow performance, software installation problems, or Windows issues caused by insufficient storage.

## Output

The script displays diskspace information for available drives in the terminal.
