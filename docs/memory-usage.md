# Memory Usage

## Purpose

Displays the total, used, and available physical mmory on the Windows computer.

## Usage

Run the script:

```powershell
.\scripts\memory-usage.ps1
```

## Information Displayed

- Total physical memory
- Used physical memory
- Available physical memory

## Troubleshooting Use

This tool can help investigate performance issues related to high memory usage or limited availablel memory.

## Output

The script displays memory amounts in gigabytes.
