# IP Configuration

## Purpose

Displays the computer's current IP configuration information.

## Usage

Run the script:

```powershell
.\scripts\ip-configuration.ps1
```

## Information Displayed

- IPv4 address
- IPv6 address
- Subnet mask
- Default gateway
- DNS server information
- Network adapter information

## Troubleshooting Use

This tool can help identify IP configuration problems when troubleshooting network connectivity, DHCP, gateway, or DNS issues.

## Output

The script displays the current IP configuration information in the terminal.
