# Installed Software

## Purpose

Displays software installed on the Windows computer

## Usage

Run the script:

```powershell
.\scripts\installed-software.ps1
```

## Information Displayed

- Software name
- Software version
- Publisher
- Installation information

## Troubleshooting Use

This tool can help identify installed applications when investigating software issues, compatibility problems, or determining whether a required application is installed.

## Output

The script displays installed software information in the terminal.
