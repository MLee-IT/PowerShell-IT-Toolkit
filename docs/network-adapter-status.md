# Network Adapter Status

## Purpose

Displays the status and configuration details of network adapters on the Windows computer.

## Usage

Run the script:

```powershell
.\scripts\network-adapter-status.ps1
```

## Information Displayed

- Adapter name
- Interface description
- Connection status
- Link speed
- MAC address

## Troubleshooting Use

This tool can help determine whether a network adapter is connected and operating properly when investigating network or connectivity problems.

## Output

The script displays network adapter information in a table.
