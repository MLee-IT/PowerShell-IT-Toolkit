# Environment Variables

## Purpose

Displays system-level environment variables configured on the Windows computer.

## Usage

Run the script:

```powershell
.\scripts\environmemt-variables.ps1
```

## Information Displayed

- Environment variable names
- Environment variable values

## Troubleshooting Use

This tool can help inspect system environment variables when troubleshooting application configuration, command-line tools, or system paths.

## Output

The script displays system environment variables in alphabetical order.
