# Windows Update Check

## Purpose

Checks the status of the Windows Update service.

## Usage

Run the script:

```powershell
.\script\windows-update-check.ps1
```

## Information Displayed

- Service name
- Display name
- Current status
- Start type

## Troubleshooting Use

This tool can help determine whether the Windows Update service is available and running when investigating Windows Update problems.

## Output

The script displays the Windows Update service information in the terminal.
