# System Information

## Purpose

Displays basic system and Windows information from the computer.

## Usage

Run the script:

```powershell
.\scripts\system-info.ps1
```

## Information Displayed

- Computer name
- Windows version
- Operating system information
- System architecture
- Manufacturer information
- Computer model

## Troubleshooting Use

This tool can help quickly identify the computer's operatng system and hardware information when troubleshooting system issues.

## Output

The script displays basic system information in the terminal.
