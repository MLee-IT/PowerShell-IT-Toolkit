# Disk Health

## Purpose

Displays the health and operational status of physical disks installed in the Windows computer.

## Usage

Run the script:

```powershell
.\scripts\disk-health.ps1
```

## Information Displayed

- Disk name
- Media type
- Health status
- Operational status
- Disk size

## Troubleshooting Use

This tool can help identify potential physical disk health or operational issues when investigating storage problems.

## Output

The sript displays physical disk information in a table.
