# DNS Cache

## Purpose

Displays the current DNS client cache on the Windows computer.

## Usage

Run the Script:

```powershell
.\scripts\dns-cache.ps1
```

## Information Displayed

- DNS entry
- Record name
- Record type
- Status
- DNS data

## Troubleshooting Use

This tool can help inspect cached DNS information when investigating name resolution or connectivity problems.

## Output

The script displays the current DNS client cache in a table.
