# Ping Test

## Purpose

Tests network connectivity between the computer and a specified destination.

## Usage

Run the script:

```powershell
.\scripts\ping-test.ps1
```

When prompted, enter a hostname or IP address.

Example:

`google.com`

## Information Displayed

- Destination
- Connectivity result
- Response time
- Packet response information

## Troubleshooting Use

This tool can help determine whether a computer can communicate with a specific network destination when troubleshooting connectivity problems.

## Output

The script displays the ping results in the terminal.
