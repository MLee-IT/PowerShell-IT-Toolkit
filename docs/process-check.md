# Process Check

## Purpose

Displays currently running processes on the Windows computer.

## Usage

Run the script:

```powershell
.\scripts\proceess-check.ps1
```

## Information Displayed

- Process name
- Process ID
- CPU usage
- Memory usage

## Troubleshooting Use

This tool can help identify running applications and processes when investigating performance issues, unresponsive programs, or unexpected system activity.

## Output

The script displays currently running processes in the terminal.
